# 服装予報

豊橋と東京の2週間の天気を表示し、その日の体感温度から服装を6段階で示すスマホ向けアプリ（PWA）。

**公開版： https://junki1218.github.io/fukuso-yohou/**

---

## スマホに入れる（公開版）

上のURLをスマホで開いて、

- **iPhone** — Safari の共有ボタン → 「ホーム画面に追加」
- **Android** — Chrome のメニュー → 「アプリをインストール」

https で配信しているので、追加すると全画面で開き、オフラインでも前回の予報が出る。

---

## 手元で動かす

```bash
python -m http.server 8123 --directory app
```

ブラウザで `http://localhost:8123` を開く。
（Claude Code からは `.claude/launch.json` の `fukuso-yohou` で起動できる）

**サーバは必須。** `index.html` をファイルとして直接開くと、Service Worker が動かず
PWA として振る舞わない。

### 同じLANのスマホから見る

同じ Wi-Fi 上のスマホから `http://<PCのIP>:8123` で開ける（動作確認用）。

> ローカルの http でも表示・操作はできるが、Service Worker は https でないと効かない。
> ホーム画面に入れて使うなら公開版（上のURL）を開くこと。

## 公開のしくみ

`main` ブランチのルートを GitHub Pages が配信している。
リポジトリ直下の `index.html` は `app/` へ送るだけのリダイレクト。
**`git push` すれば数十秒で反映される。** ビルドは要らない。

画像を差し替えたときは `python build_assets.py` を回してから push すること。
`app/sw.js` の `VERSION` を上げないと、既にホーム画面に入れた端末が
古いファイルを掴んだままになる。

## 中身

| 場所 | 中身 |
|---|---|
| `app/` | アプリ一式。**これを丸ごと置けば動く** |
| `app/img/` | `assets/` を正規化した画像（`build_assets.py` の出力。直接編集しない） |
| `assets/` | 画像AIから納品された原本20枚。**触らない** |
| `build_assets.py` | 画像の正規化と PWA アイコンの書き出し |
| `確定仕様書.md` | 決定36項目と設計の根拠 |
| `API精査レポート.md` | API比較と実測ログ |
| `画像生成リスト_v2_発注書.md` | 画像20枚の発注書 |

## 画像を差し替えたとき

`assets/` に新しい PNG を置いてから：

```bash
python build_assets.py
```

大きさと中心位置を揃えて `app/img/` に書き出す。納品原本は変更しない。

## データ

- [Open-Meteo Forecast API](https://open-meteo.com/) — APIキー不要、CORS開放、サーバ不要
- **出典表記は必須**（CC BY 4.0）。画面下部に表示している。**消さないこと**
- **無料枠は非商用限定。** 個人利用の範囲を超える場合は有料プランの契約が要る

## 記録（フィードバック）

⚙ の隣の 📝 から、**その日の体感温度・実際に着たもの・どう感じたか**を残せる。
3件たまると「目安を何℃ずらすとよさそうか」を出し、ワンタップで適用できる。
自動では変えない。**適用するかどうかは毎回こちらが決める。**

- 快適度は5段階（暑すぎた／少し暑かった／ちょうどよかった／少し寒かった／寒すぎた）
- 「ちょうどよかった」を0として平均し、**快適度1目盛り＝約2℃**として換算する
  （服装1段階の幅が約4℃のため）
- 段階ごとの偏りも表で出る。特定の段階だけ直したいときは ⚙ で数字を手で書き換える

### 記録の保存先

**この端末のブラウザ（localStorage）。** サーバには送らない。
機種変更・履歴の削除・プライベートウィンドウで消えるので、
「履歴」タブの**書き出し**で JSON を保存しておくと復元できる（しきい値も一緒に入る）。

## 設定を変える

| 変えたいもの | 場所 |
|---|---|
| 服装の切り替わる気温 | ⚙ で**1段階ずつ数字を直接編集**。プリセット（暑がり/標準/寒がり ±2℃）もある |
| その既定値そのもの | `app/app.js` の `DEF_TH` |
| 快適度1目盛りの重み | `app/app.js` の `suggest()`（既定は2℃） |
| 傘・長靴を出す降水確率 | `app/app.js` の `POP_UMBRELLA` / `POP_BOOTS` |
| 地点 | `app/app.js` の `CITIES` |
| 段階色 | `app/styles.css` の `--lv1`〜`--lv6` |

段階色はライト/ダークで反転させていない。アイコン画像が1枚しかなく濃い輪郭線で
描かれているため、チップを暗転させると線が読めなくなる（確定仕様書 §3-2 注2）。
